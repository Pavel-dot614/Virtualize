# 🚀 Виртуализация и блокировка рендеринга — демонстрация производительности

## ❓ Зачем нужна виртуализация списков

Виртуализация — это техника оптимизации производительности, при которой в DOM рендерятся только видимые элементы списка, а не весь массив данных. Это особенно важно при работе с большими списками (сотни или тысячи элементов), чтобы:

- 📈 Повысить производительность и отзывчивость интерфейса
- 💾 Снизить потребление памяти браузером
- 🚫 Избежать "зависаний" и долгой отрисовки при прокрутке

**Когда использовать виртуализацию:**

- Если список содержит более 100–200 элементов
- При динамической подгрузке данных (бесконечная прокрутка)
- Для мобильных и слабых устройств, где важна экономия ресурсов

Этот проект демонстрирует два ключевых аспекта оптимизации загрузки на фронтенде:

- ⚡ **Виртуализация списков в React** с помощью `react-window`
- 🧱 **Блокировка рендеринга** в обычной HTML-странице из-за тяжёлого JavaScript

⚙️ Как работает виртуализация под капотом
Когда у нас есть длинный список (например, из 10 000 элементов), если мы попытаемся отрисовать его полностью — браузер повиснет, особенно на слабых устройствах.

Виртуализация решает это так:

📏 Измеряет размеры контейнера и высоту (или ширину) одного элемента.

🎯 Вычисляет, какие элементы попадают в видимую область (viewport).

🧹 Рендерит только эти видимые элементы, плюс небольшой буфер сверху и снизу.

📜 Имитирует полный список с помощью "пустого пространства" (padding / translateY), чтобы прокрутка ощущалась как настоящая.

Это работает благодаря позиционированию и виртуальной прокрутке, а не физическому наличию всех элементов в DOM.

💤 Виртуализация + Ленивые загрузки (Lazy Loading)
Виртуализация хорошо работает в паре с ленивой загрузкой изображений или данных, особенно в длинных списках, где каждое изображение может весить по несколько мегабайт.

Комбинация даёт двойной эффект:

🔧 Виртуализация — рендерит только видимые элементы в DOM

💤 Lazy loading — загружает тяжёлый контент (изображения, видео, компоненты) только тогда, когда он входит в область видимости

📈 Результат:
Снижается нагрузка на сеть и CPU

Страница загружается быстрее

Повышается UX на слабых устройствах

🧱 Реализация виртуализации на практике

С react-window

```
import { FixedSizeList as List } from 'react-window';

<List
  height={600}
  itemCount={items.length}
  itemSize={50}
  width="100%"
>
  {({ index, style }) => (
    <div style={style}>
      {items[index].label}
    </div>
  )}
</List>
```

Что происходит:

height — высота видимой области

itemSize — фиксированная высота одного элемента

react-window сам считает, какие индексы попадают в видимую зону и вызывает только их

🚧 Важно помнить
Виртуализация не работает при SSR — компоненты используют window, scrollHeight, и т. д., только на клиенте.

Поэтому используем useEffect или проверяем typeof window !== 'undefined' для безопасности.

Не забывай про key для элементов — React должен отслеживать изменения правильно.
